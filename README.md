# CAT 2 DSA MCQ Quiz Platform ⚡

An interactive, responsive web application for practicing **130 Multiple Choice Questions** across **13 Data Structures & Algorithms topics** (Stacks and Linked Lists), tailored for VIT Competitive Coding CAT 2.

🔗 **Live Website**: [https://joserohit264.github.io/CC_CAT2_MCQ/](https://joserohit264.github.io/CC_CAT2_MCQ/)

---

## 🌟 Features

- **Instant Answer Denotation**: Correct selections turn **Emerald Green** with `✓`; wrong selections turn **Rose Red** with `✗` while highlighting the correct choice.
- **Detailed Explanations**: Algorithmic reasoning displayed immediately upon answering.
- **Analytics & Stats**: Tracks Score, Accuracy %, Total Attempted out of 130, and 🔥 Active Streak.
- **Topic Filtering & Search**: Practice by topic or all 130 MCQs, search by keyword, or review bookmarked questions.
- **Keyboard Shortcuts**: `Space` / `Right Arrow` (Next), `Left Arrow` (Prev), `1-4` (Options A-D).
- **Persistent Progress**: Saved automatically via `localStorage`.
